# IMU Test

M5Stack系デバイス上の UIFlow2 / MicroPython 環境で動作する、6軸IMU確認プログラムです。

## 対象デバイス

このプロジェクトは、M5Stack系デバイス上の UIFlow2 / MicroPython 環境で動作する 6軸IMU確認プログラムです。

想定条件:

- UIFlow2ファームウェアが利用できるM5Stack系デバイス
- 加速度センサーとジャイロセンサーを搭載していること
- `M5`, `Widgets`, `hardware`, `Imu` または `IMU`, `BtnA` API が利用できること
- 画面サイズは 128x128 程度を想定

注意: 現時点では対象機種を固定していません。AtomS3系などの小型画面付きIMU搭載デバイスが想定に近いですが、実機での確認が必要です。

## Windowsでのセットアップ手順

1. M5Stack公式サイトから Windows版 M5Burner をダウンロードして展開します。
2. M5Stack Community アカウントを作成し、M5Burnerにログインします。
3. 使用するデバイスをUSBケーブルでWindows PCに接続します。
4. デバイスが認識されない場合は、USBシリアルドライバをインストールします。
   - CP210x系ドライバ
   - CH9102系ドライバ
5. Windowsのデバイスマネージャーで、接続されたデバイスのCOMポートを確認します。
6. M5Burnerで対象デバイスに対応する UIFlow2 ファームウェアを選択します。
7. `Burn` を実行し、必要に応じてWi-Fi情報や起動オプションを設定します。

## UIFlow2での実行手順

1. UIFlow2 Web IDE を開きます。
2. M5Burnerと同じM5Stack Communityアカウントでログインします。
3. 対象デバイスを選択します。
4. USB接続またはWi-Fi接続でデバイスに接続します。
5. `main.py` の内容をUIFlow2のPythonコードエディタに貼り付けます。
6. `Run` を実行してデバイス上でプログラムを起動します。
7. 画面に `6-AXIS CHECK` と表示され、加速度・ジャイロ値が更新されることを確認します。
8. デバイスを傾けたり動かしたりして、以下の表示が `OK` になることを確認します。
   - `S`: 静止状態のIMU値が妥当
   - `A`: 加速度の変化を検出
   - `G`: ジャイロの変化を検出
9. `BtnA` を押すとテスト状態をリセットできます。

## トラブルシュート

### Windowsでデバイスが認識されない

- USBケーブルがデータ通信対応か確認してください。
- 別のUSBポートに接続してみてください。
- デバイスマネージャーでCOMポートが表示されるか確認してください。
- CP210xまたはCH9102のUSBシリアルドライバをインストールしてください。

### M5BurnerでBurnできない

- M5Burnerにログインしているか確認してください。
- 正しいデバイス向けのUIFlow2ファームウェアを選択してください。
- 正しいCOMポートを選択してください。
- 他のシリアル通信ツールやUIFlow2が同じCOMポートを使用していないか確認してください。
- 必要に応じてデバイスを再起動し、再度Burnしてください。

### UIFlow2からデバイスに接続できない

- M5BurnerとUIFlow2で同じアカウントを使用しているか確認してください。
- Wi-Fi接続の場合、デバイスが同じネットワークに接続されているか確認してください。
- USB接続の場合、ブラウザがシリアルポートへのアクセスを許可しているか確認してください。
- UIFlow2で正しいデバイス種別を選択してください。

### 実行時に `IMU API ERROR` と表示される

- 対象デバイスにIMUが搭載されているか確認してください。
- UIFlow2ファームウェアが対象デバイスに正しく書き込まれているか確認してください。
- `Imu` または `IMU` API が利用できるデバイスか確認してください。
- ファームウェアを最新のUIFlow2に更新して再実行してください。

### 画面表示が崩れる

- このプログラムは 128x128 程度の画面を想定しています。
- 画面サイズや回転方向が異なるデバイスでは、ラベル位置や描画座標の調整が必要です。
- `Widgets.setRotation(0)` の値を変更すると表示向きが改善する場合があります。

### `S`, `A`, `G` が `OK` にならない

- 起動直後の約1秒間はデバイスを静止させてください。
- キャリブレーション後にデバイスを傾けると `A` が `OK` になります。
- キャリブレーション後にデバイスを回転させると `G` が `OK` になります。
- 反応しない場合は `BtnA` を押してリセットし、再度試してください。
